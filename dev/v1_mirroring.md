# V1 坐标与镜像规则

V1 以 `6deb462` 的单臂、双臂坐标定义为基准。整体坐标转换实验 `274794e` 已撤销；关节零点、正方向、限位、mesh、质量和惯量保持原定义。

当前仍使用 V1 原入口和配置文件布局。手臂关节输出复用 `assets/common/links.xacro` 的 `openarm_emit_joint`，由 V1 宏加载旧格式的 origin、axis 和 limit；完整的 preset/组件目录迁移是下一步。

## 左侧镜像范围

`assets/robot/openarm_v1.0/config/arm/mirroring.yaml` 声明两组范围：

- link0、1、2、5、6、7：沿局部 Y 镜像 visual、collision、COM 和惯量；link3、4 使用同一零件定义。
- J1、J2、J3、J6、J7：使用公共关节镜像规则。J4、J5 保留原局部连接位置。

关节 origin 的旋转使用 `S R S`，其中 `S = diag(1,-1,1)`。V1 调用公共宏时显式启用 `reflect_rotation`，使双臂 J2 的右侧 +90 度安装变为左侧 -90 度。V2 现有调用的默认行为保持不变。

J4 的局部 Y 偏移为 +31.5 mm，J5 为 -31.5 mm，左右相同。把 J5 纳入位置镜像会令后续结构产生 63 mm 的偏移。旧 V1 的 J5 调用虽传入 `reflect`，旧宏仅用它处理 `rpy`，没有翻转 `xyz`；这里保留的正是原来的正确连接。

## 单臂与双臂

| 模式 | 根安装绕 X | J2 origin 绕 X | J2 限位 | J7 局部轴 |
| --- | ---: | ---: | --- | --- |
| 默认单臂 | 无固定安装旋转 | 0 | 约 -100 到 +100 度 | +Y |
| 双臂右侧 | 约 +90 度 | 约 +90 度 | 约 -10 到 +190 度 | +Y |
| 双臂左侧 | 约 -90 度 | 约 -90 度 | 约 -190 到 +10 度 | -Y |

单臂零位时，link0–7 的坐标轴保持同向，根 link 仍为 link0。双臂保留原来的旋转式安装。

左臂限位从右侧区间反向得到。J2 先形成右侧安装对应的限位，再反向生成左侧限位。J1 不再使用写死的 -120 度平移来表达左右关系。

关节正方向保留：J1 +Z、J2 -X、J3 +Z、J4 +Y、J5 +Z、J6 +X；J7 右侧 +Y、左侧 -Y。硬件控制参数及关节指令不作符号转换。

## 验证

对照 `6deb462` 展开的模型，检查单/双臂、前缀开关、ROS2 control 开关共 8 种 V1 输出。所有 link/joint 的名称、连接关系、mesh、origin、axis、质量、COM、惯量、限位、mimic 和控制接口按数值比较保持一致。

另外对照 5 个 V2 preset 和独立 parallel gripper 输出，检查公共宏修改没有改变已有模型。`test/test_v1_mirroring.py` 固定检查单臂零位坐标、双臂 J2 安装与限位、J4/J5 连接偏移及电机正方向。
